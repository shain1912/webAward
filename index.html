Studio

부산에서, 끝까지

Good software is quiet. We hide the complexity behind the infrastructure and ship only the intent.

KodeKorea는 부산에 기반한 개발·교육 스튜디오입니다. 한쪽에선 대학·공공기관·기업의 웹과 앱, TeamHub 같은 자체 프로덕트를 만들고, 다른 한쪽에선 교육용 IDE와 영상 강의, 해커톤으로 다음 세대 개발자를 키웁니다.

두 축은 서로를 먹여 살립니다. 현장에서 쌓은 개발 실력이 교육의 재료가 되고, 해커톤과 강의에서 만난 사람들이 다시 프로젝트로 이어집니다. 모든 서비스는 자체 클라우드 '허준클라우드' 위에서 돌아가 외부 호스팅 비용 없이 빠르게 움직입니다.
